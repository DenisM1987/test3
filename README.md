# Анализатор транзакций

Приложение для анализа банковских транзакций из Excel-файла.

## Функциональность

- Генерация JSON-данных для веб-страниц
- Анализ транзакций
- Формирование отчетов

## Установка

1. Установите Poetry: `pip install poetry`
2. Установите зависимости: `poetry install`
3. Создайте файл `.env` на основе `.env_template`
4. Запустите приложение: `poetry run python src/main.py`
